## Sprint Mechanics

**跑動力學**　描述「跑起來的樣子」的詞。這些是教練在跑道邊觀察與錄影回放時使用的語言。

| English | 中文 | 說明 |
| --- | --- | --- |
| Block Clearance | 起跑架推離 | 從槍響到雙腳離開起跑器的整個動作。看的是推蹬方向與離架時的軀幹角度，而不是誰先站起來。 |
| Drive Phase | 加速推進期 | 起跑後身體仍明顯前傾、每一步都在增加速度的階段，一般約前 20–30 公尺。此時的力量主要用於水平推進。 |
| Transition Phase | 轉換期 | 由前傾的推進姿勢過渡到直立跑姿的過程。過早站直會提早結束加速，拖太久則進不了最高速。 |
| Maximum Velocity | 最大速度 | 一趟跑動中所能達到的最高瞬時速度，通常出現在 30–60 公尺之間。它是短跑成績的天花板。 |
| Speed Endurance | 速度耐力 | 在接近最高速的狀態下維持速度、抵抗減速的能力。決定 60 公尺之後的表現。 |
| Deceleration | 減速 | 最高速之後不可避免的掉速。名次往往取決於誰掉得比較少，而不是誰的最高速比較快。 |
| Ground Contact Time (GCT) | 觸地時間 | 腳掌接觸地面的時間，優秀短跑選手在最高速時約 0.08–0.10 秒。觸地時間變長是疲勞最早出現的訊號之一。 |
| Flight Time | 騰空時間 | 兩次觸地之間身體離地的時間。與觸地時間的比例決定跑動的節奏與效率。 |
| Stride Length | 步幅 | 每一步前進的距離。刻意拉大步幅通常會讓腳掌落在重心前方而產生制動，反而變慢。 |
| Stride Frequency | 步頻 | 每秒的步數。步頻與步幅相乘就是速度，兩者無法同時最大化，訓練是在找平衡點。 |
| Front Side Mechanics | 前側力學 | 大腿在身體前方完成抬起與下放的動作模式，是高速跑動的特徵。 |
| Backside Mechanics | 後側力學 | 腳留在身體後方過久、靠折疊小腿回收的模式。常見於加速期尚未結束就直立的跑者。 |
| Shin Angle | 脛骨角度 | 觸地瞬間小腿與地面的夾角。加速期需要明顯前傾的角度來產生水平推進力。 |
| Braking Force | 制動力 | 腳掌落在重心前方時產生的向後作用力。是「跑得很用力卻不快」最常見的原因。 |
| Triple Extension | 三關節伸展 | 髖、膝、踝在推蹬瞬間同時伸展。加速期與奧林匹克舉共用的發力模式。 |
| Dorsiflexion | 足背屈 | 腳尖朝上勾起的踝關節位置。維持足背屈能讓小腿像彈簧一樣儲存與回彈能量。 |

## Physiology & Force

**生理與發力**　解釋「為什麼會快、為什麼會累」的詞。訓練安排的休息時間與課間隔都由這些概念決定。

| English | 中文 | 說明 |
| --- | --- | --- |
| Alactic (ATP-PC) System | 磷酸原系統 | 6–10 秒內全力輸出的能量來源，不產生乳酸。100 公尺的主要供能系統，恢復需要數分鐘而非數十秒。 |
| Glycolytic System | 醣解系統 | 約 10–60 秒的高強度供能途徑，伴隨乳酸與氫離子堆積。200/400 公尺的主戰場。 |
| Lactate Tolerance | 耐乳酸能力 | 在代謝物堆積、肌肉發燙的狀態下仍維持動作品質的能力。這類課恢復慢，通常一週不超過一次。 |
| Neuromuscular Fatigue | 神經肌肉疲勞 | 神經徵召能力下降造成的疲勞，肌肉不一定痠。表現是速度掉、觸地變長，但自覺還「跑得動」。 |
| Rate of Force Development (RFD) | 發力率 | 單位時間內能產生多少力量。短跑觸地只有 0.1 秒，能用出多少力比最大力量本身更重要。 |
| Stretch-Shortening Cycle (SSC) | 伸展—收縮循環 | 肌腱先被拉長儲存彈性能，再迅速回彈釋放。跑步、跳躍的效率核心。 |
| Reactive Strength Index (RSI) | 反應力量指數 | 跳躍高度除以觸地時間，用來量化彈性能力。可作為疲勞監控的日常指標。 |
| Elastic Stiffness | 彈性剛度 | 觸地瞬間下肢抵抗塌陷的能力。剛度不足時力量會被關節吸收而非傳回地面。 |
| Eccentric Strength | 離心力量 | 肌肉被拉長時抵抗的力量。膕繩肌在擺動末期正是離心收縮，也是拉傷最常發生的瞬間。 |
| Power-to-Weight Ratio | 功率體重比 | 相對於體重的輸出功率。短跑增重只有在功率同步增加時才有意義。 |

## Training Methods

**訓練手段**　跑道與重量室裡實際會用到的手段名稱。用同一套詞彙，教練與運動員才不會各說各話。

| English | 中文 | 說明 |
| --- | --- | --- |
| Flying Sprint | 飛行跑 | 先以助跑段加速，再進入計時區跑最高速。訓練最大速度最直接的手段。 |
| Resisted Sprint | 阻力跑 | 拖／推雪橇或穿阻力帶的加速跑。阻力以掉速不超過約 10% 為原則，太重會改變跑姿。 |
| Assisted Sprint (Overspeed) | 助力跑（超速跑） | 以彈力繩或下坡協助跑出超過自身最高速的速度，用來提升步頻上限。風險較高。 |
| Tempo Run | 節奏跑 | 約 60–75% 強度的中低強度反覆跑，用於恢復與有氧底子，不是拿來追成績的課。 |
| Extensive / Intensive Tempo | 廣泛／密集節奏跑 | 廣泛節奏強度低、量大，屬恢復性質；密集節奏強度接近 80–89%，已具訓練壓力。 |
| Special Endurance | 特殊耐力 | 以比賽距離或稍長的距離、接近比賽強度進行的課，例如 300／250／200 遞減。 |
| Plyometrics | 增強式訓練 | 利用伸展—收縮循環的跳躍訓練。以落地次數而非時間計量，並排在疲勞之前進行。 |
| Contrast / Complex Training | 對比訓練 | 重負荷動作後緊接爆發動作（如深蹲接跳箱），利用後激活增益提升輸出。 |
| Post-Activation Potentiation (PAP) | 後激活增益 | 重負荷刺激後短時間內爆發表現提升的現象。賽前激活課的理論依據。 |
| Wicket Drills | 標誌欄跑 | 以等距矮欄架強制固定步幅與觸地位置，用來建立最高速的跑姿。 |
| Wall Drill | 推牆練習 | 手扶牆維持前傾角度做原地推蹬，用於建立加速期的姿勢與節奏。 |
| A-Skip / B-Skip | A 字跳／B 字跳 | 把跑步動作拆解的熱身練習：A 強調抬膝與觸地，B 再加上小腿前伸與扒地。 |
| Acceleration Ladder | 加速階梯 | 距離逐段遞增的加速跑（如 20／30／40 公尺），讓加速姿勢逐步過渡到直立。 |
| Blocks Start | 蹲踞式起跑 | 使用起跑架的正式起跑。包含各就位、預備、槍響三個階段的節奏。 |

## Load & Monitoring

**負荷與監控**　ATM 系統實際計算與追蹤的指標。這些數字讓「今天要練多重」從感覺變成有依據的判斷。

| English | 中文 | 說明 |
| --- | --- | --- |
| Session RPE (sRPE) | 課後主觀強度 | 課後 30 分鐘給出的 1–10 分自覺強度，乘以實際訓練時長就是該堂課的訓練負荷。 |
| Training Load (AU) | 訓練負荷 | sRPE × 時長所得的任意單位（AU）。單位本身沒有意義，有意義的是它跨週的變化。 |
| Acute:Chronic Workload Ratio (ACWR) | 急慢性負荷比 | 近 7 天負荷相對於近 28 天平均週負荷的比值。約 0.80–1.30 為相對安全區間，過高代表增量太快。 |
| Monotony | 單調度 | 一週內每日負荷的平均值除以標準差。數值高代表每天都一樣重，缺乏高低起伏，與過度訓練相關。 |
| Strain | 訓練壓力 | 週總負荷乘以單調度。同樣的總量，分佈越平均，身體承受的壓力越大。 |
| Readiness | 準備度 | 由睡眠、痠痛、壓力與疼痛換算的每日狀態分數，用來決定當天要不要照原計劃練。 |
| Volume / Intensity | 量／強度 | 量是做了多少（距離、組數），強度是做得多接近極限（% 最佳成績、% 1RM）。兩者不應同時往上加。 |
| Density | 密度 | 同樣的工作量壓縮在多短的時間內完成。縮短休息就是提高密度，也提高了實際強度。 |
| Periodisation | 週期化 | 把訓練依時間切成階段，讓能力在目標賽事時達到高峰的安排方式。 |
| Macro / Meso / Microcycle | 大／中／小週期 | 分別對應整個賽季、數週的訓練階段，以及一週的課表結構。 |
| Tapering | 賽前減量 | 賽前降低訓練量但維持強度，讓疲勞消退而能力保留。通常需要 7–14 天。 |
| Supercompensation | 超量恢復 | 適當負荷後身體恢復到高於原有水準的現象。恢復不足就練下一課，累積的是疲勞而不是進步。 |
| Load Spike | 負荷驟增 | 單週負荷相對於前期基線大幅上升。是可預測性最高的受傷前兆之一。 |
| Personal Best (PB) / Season Best (SB) | 個人最佳／本季最佳 | 個人歷來與本季的最佳成績。是分析趨勢與設定目標時的基準線。 |

## Injury & Availability

**傷患與可用度**　傷患管理的共同語言。能不能站上跑道，比任何一堂課的內容都重要。

| English | 中文 | 說明 |
| --- | --- | --- |
| Hamstring Strain | 膕繩肌拉傷 | 短跑最常見的傷患，多發生於高速擺動末期。復發率高，回歸過早是主要原因。 |
| Niggle | 輕微不適 | 尚未影響訓練、但持續存在的小痛。及早記錄能避免它變成真正的傷患。 |
| Availability | 可用度 | 運動員能夠正常參與訓練與比賽的時間比例。長期表現的最強預測指標。 |
| Return to Run (RTR) | 回歸跑動 | 傷後由復健過渡到跑道的階段，以漸進的速度與量重新暴露於跑動負荷。 |
| Return to Play (RTP) | 回歸比賽 | 通過力量、活動度與速度的客觀檢核後恢復完整訓練與比賽。應以標準判定，而非以天數判定。 |
| Pain Monitoring | 疼痛監控 | 以 0–10 分記錄靜態與活動時的疼痛。ATM 在活動時疼痛達門檻時，當日高強度課會自動降級。 |
| Exercise Modification | 替代動作 | 依受傷部位把原本的動作換成不加重傷勢的版本，讓訓練得以繼續而非全面停止。 |

---

訓練課表不是罐頭。這些詞是共同語言，實際的內容要由教練在持續訓練中逐步了解運動員的能力與進度後，才長得出來——ATM 負責把過程完整記錄下來並轉成分析。
